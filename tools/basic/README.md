# tools/basic

基础工具。这里的工具在 agent 启动时直接暴露给模型，不经过 `Tool Search` 的检索管道。

## 判定标准

一个工具能放进这个目录，必须同时满足三个条件：

1. **只读**：调用不改变任何持久状态。
2. **无副作用**：不触发任何外部动作，包括通知、下单、写日志以外的第三方调用。
3. **可确定性验证**：给定输入，输出能在不依赖外部系统的条件下被独立复核。

三个条件缺一不可。只读但结果依赖外部世界的（实时汇率、天气），不在此列；输出可验证但有副作用的，也不在此列。

满足条件的工具数量有界，通常不超过几十个，低于模型工具选择准确率的退化拐点，因此适合常驻上下文，而不需要走检索。

## 文件清单

| 文件 | 职责 |
|---|---|
| `math_tools.py` | 纯算术运算 |
| `unit_convert.py` | 单位换算 |
| `time_tools.py` | 时间解析、格式化、时区转换 |
| `text_tools.py` | 字符串处理 |
| `encoding_tools.py` | 编码与哈希 |
| `validation_tools.py` | 结构与格式校验 |
| `random_tools.py` | 带种子的确定性随机 |

## 各文件边界

### `math_tools.py`

纯算术，输入数字、输出数字。加减乘除、幂、取整、四舍五入、百分比、最大最小值、求和。所有输出都能被 Python 的 `decimal` 或 `fractions` 独立复核。

### `unit_convert.py`

单独成文件，因为它依赖换算表而不是算术规则。长度、重量、温度、货币（汇率快照固定时）。温度换算是仿射变换，和纯比例换算不同，放在这里比塞进 `math` 更清楚。

### `time_tools.py`

解析、格式化、时区转换、两个时间点之差、加/减时长。

有一个边界需要标注：`now()` 不严格满足可确定性验证——同一时刻调用两次结果不同。但它对“把相对时间转成绝对时间”是必要的，因此保留在此目录，并在工具描述中注明“结果依赖调用时刻”。

### `text_tools.py`

字符串长度（按字符/字节/token 分别计）、大小写转换、截断、替换、正则匹配与提取。输出都能用字符串操作复核。

### `encoding_tools.py`

base64、URL encode/decode、MD5/SHA256。hash 是确定性的，同一输入永远同一输出，适合放在基础工具里。

### `validation_tools.py`

JSON 语法校验、JSON Schema 校验、类型检查、正则整串匹配。输出是布尔值或错误列表，可独立复核。

### `random_tools.py`

只有在显式传入种子时才满足可确定性验证。不带种子的随机数不属于基础工具。接口设计上强制要求 `seed` 参数，缺少种子时直接报错，而不是回退到系统熵源。
